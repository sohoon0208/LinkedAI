# LinkedAI execution safety

LinkedAI is an orchestration contract, not permission to bypass host
sandboxing, repository protections, credentials, or operating-system safety.

- LUNA is the only normal source editor.
- ASTRA and SOL receive compressed evidence and do not edit or browse the
  target repository directly.
- The controller does not fabricate receipts, model identity, test results, or
  completion state.
- The user's request authorizes only the stated intent and scope. A pure
  investigation, review, or explanation cannot mutate source.
- A changed strategy, scope, or acceptance criterion requires a fresh packet
  and ASTRA plan.
- SOL is the only completion authority in main LinkedAI, and its `DONE` still
  requires a fresh valid completion bundle.

Destructive operations, history rewriting, production changes, and irreversible
migrations use the host's normal safety rules and explicit user authorization.

Do not put credentials, private keys, or unnecessary sensitive data in packets,
prompts, fixtures, or logs. Keep raw logs and run artifacts outside the
fingerprinted subject repository.

Antigravity is not part of LinkedAI. LinkedAI does not launch AG, grant AG
permissions, or treat an AG `SUCCESS` field as proof. Use the separately
installed ChatGravity skill when an Antigravity workflow is explicitly needed.
